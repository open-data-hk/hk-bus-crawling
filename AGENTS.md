# Agent Instructions

## Pull requests

- This repo (`open-data-hk/hk-bus-crawling`) is a fork of `hkbus/hk-bus-crawling`.
- **Never open a pull request against the upstream repo (`hkbus/hk-bus-crawling`).**
- All pull requests must be opened on **this repo** (`open-data-hk/hk-bus-crawling`).
- If using the `gh` CLI, make sure the default repo is set correctly first:
  `gh repo set-default open-data-hk/hk-bus-crawling`
